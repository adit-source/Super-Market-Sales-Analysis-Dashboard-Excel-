# 🛒 Super Market Sales Analysis & Dashboard

## 📌 Project Overview

This project analyzes supermarket/e-commerce sales data for the year 2022 to identify sales trends, customer behavior, product performance, order status, and channel-wise performance.

The project uses data analysis and visualization techniques to transform raw sales data into meaningful business insights that can support better decision-making.

## 🎯 Objectives

The main objectives of this project are:

* Analyze overall sales performance
* Compare sales between male and female customers
* Identify top-performing states
* Analyze sales across different sales channels
* Understand order status distribution
* Identify the best-performing product categories
* Analyze monthly sales and order trends
* Understand customer purchasing behavior
* Create an interactive dashboard for business reporting

## 🔍 Key Insights

### 👩 Gender Analysis

Female customers generated approximately **₹13.56M** in sales, while male customers generated approximately **₹7.61M**.

This indicates that female customers contributed a significantly larger share of overall sales.

### 🛍️ Channel Analysis

The highest-sales channels were:

1. Amazon — approximately ₹7.52M
2. Myntra — approximately ₹4.94M
3. Flipkart — approximately ₹4.57M
4. Ajio — approximately ₹1.33M
5. Nalli — approximately ₹1.02M

Amazon was the strongest-performing sales channel in the dataset.

### 📍 State Analysis

The top-performing states by sales include:

1. Maharashtra — approximately ₹2.99M
2. Karnataka — approximately ₹2.65M
3. Uttar Pradesh — approximately ₹2.10M
4. Telangana — approximately ₹1.71M
5. Tamil Nadu — approximately ₹1.68M

### 📦 Category Analysis

The highest-performing categories by sales were:

* Set — approximately ₹10.51M
* Kurta — approximately ₹4.96M
* Western Dress — approximately ₹3.15M
* Top — approximately ₹1.19M
* Saree — approximately ₹1.01M

The **Set** category contributed the largest share of sales.

### 📋 Order Status

The dataset contains the following order statuses:

| Status    | Orders |
| --------- | -----: |
| Delivered | 26,356 |
| Returned  |  1,001 |
| Cancelled |    831 |
| Refunded  |    501 |

The majority of orders were successfully delivered.

## 💡 Business Recommendations

Based on the analysis:

* Focus marketing efforts on high-performing customer segments.
* Strengthen sales strategies on Amazon, Myntra and Flipkart.
* Increase inventory and promotional activity for high-performing categories such as Set and Kurta.
* Analyze return and cancellation reasons to reduce lost sales.
* Focus regional marketing campaigns on high-performing states.
* Monitor monthly sales trends to identify seasonal opportunities.
* Use customer and product-level analysis to improve personalized marketing.
